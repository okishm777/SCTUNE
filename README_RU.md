# SCTUNE v0.1 — исходники VST3

Первый экспериментальный VST3-плагин коррекции вокала для FL Studio. Включает интерфейс с чёрно-фиолетовой темой, пресеты, выбор тональности/лада, Retune Speed, Humanize, Formant Color, Mix, Bypass и индикаторы уровня.

## ВАЖНО
- Это **исходный код**, не готовый .vst3 бинарник. Проект не проходил компиляцию и прослушивание в этой среде.
- Pitch tracker рассчитан на чистый **одноголосный** вокал. Возможны ошибки октав, задержки, артефакты и щелчки.
- `Formant Color` пока лишь простая окраска тембра, **не настоящий formant shifting**.
- Нулевое положение Retune не гарантирует прозрачного звука из-за алгоритмической задержки pitch shifter. Для исходного звука включайте BYPASS.
- Визуализация — стилизованная, реагирует на уровень сигнала, но не отображает реальную форму волны по отсчётам.

## Сборка Windows
1. Установите **Visual Studio 2022** с компонентом **Desktop development with C++**, **Git** и **CMake 3.22+**.
2. Распакуйте архив, откройте **Developer PowerShell for VS 2022** в папке `SCTUNE`.
3. Выполните:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

CMake скачает JUCE 8.0.6 (нужен интернет). После сборки ищите `build\SCTUNE_artefacts\Release\VST3\SCTUNE.vst3`.
Скопируйте пакет `.vst3` в `C:\Program Files\Common Files\VST3`, затем выполните сканирование в FL Studio Plugin Manager.
